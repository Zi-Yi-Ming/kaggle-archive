# 金牌区思路（醇久科研中心 / 吃白饭的大肥鱼 2953.4）— 2026-09-27

## 原话（外部情报，非本仓代码）
- 「金牌区大部分就都不是了（纯静态），我的也不是」
- 「动态不只有rl一种」
- 「rl我局部用了一点点，因为这个数据形态呈现的结果来看其实很多地方rl价值有限」
- 「你可以去参考下我榜上的回放，**吃白饭的大肥鱼**」

## 解码（用于冲金设计）
1. **金牌 ≠ 纯静态策略**；要有**动态层**
2. **动态 ≠ 整局 PPO/RL**；RL 只该用在**信息形态支持的小决策**（如终局卖点/投放时点）
3. **主干仍是结构化策略**（路由/库存/价格响应），对手建模做模式切换
4. 「吃白饭的大肥鱼」= **识别并吃掉被动肥鱼**（囤积不动、不抢市、不会拆单的对手）
   - 对肥鱼：提前卖/抢价格窗口/让他们库存变纸
   - 对狠家：保守、不自相残杀、保终局现金

## 可执行设计（P100 Fish Eater）
```
Metav4/H3 底座（已证 shop 安全）
+ 对手指纹（前 50 步）:
    被动度 = 1 - 对方市场单频率
    囤积度 = 对方 shed 增速
    抢跑度 = 对方与我同向 SELL 重合率
+ 模式:
    FISH  (被动度高、囤积高): 终局更贪 / 提前放量卖 / 限对方跟进
    SHARK (抢跑高、镜像紧): 保守 cap / 拆单 / 不抢第一天价格
    NEUTRAL: H3 原样
+ 局部小 RL（可选）: 仅在 day26-29 选择 cap ∈ {40,60,80,120} 的卖出档位
```
